# 配置中心使用说明

1.仅 **V4.1.0** 之后的版本中支持该配置页面 2.此处配置的优先级最高，它将**覆盖**`Vercel环境变量`、覆盖`blog.config.js`。 3.您可以在`blog.config.js`以及各个主题的`config.js`中找到所有支持配置的`配置名`与`配置值` 4.并非所有配置都支持，例如`NOTION_PAGE_ID`,`LINK`就不支持在这里配置等

## 表格字段说明

| 说明 | 表头字段 |
| --- | --- |
| 想要生效的配置，请将其勾选 | 启用 |
| 参阅配置文件变量名，例如 `AUTHOR` | 配置名 |
| 输入您的值 例如作者名 `tangly1024` ， 或者 `true` / `false`  | 配置值 |
| 仅作为备忘说明使用 | 配置备注 |
| 如果配置的值是一张图片，可以在这里上传 | 配置附件 |

请不要修改这里的表头，除非你知道在哪里修改对应的代码。
